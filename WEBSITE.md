# AetherMesh

AI operating systems for companies that need more execution capacity without building a large specialist team.

## Company website

The public company site lives in [site/index.html](site/index.html) and is deployed through GitHub Pages by [the Pages workflow](.github/workflows/aethermesh-pages.yml).

**Website:** once GitHub Pages is enabled for the repository, GitHub will publish the site at the repository's Pages URL.

## What AetherMesh does

Find the work worth automating. Design the agent system. Prove it safely. Operate it.

The commercial product family includes MeshOps, MeshGuard, MeshSupport, MeshRevenue, MeshDesk, MeshFinOps, MeshData and MeshIntel.

See [company](company/), [products](products/) and [revenue](revenue/) for the operating model and sales system.
