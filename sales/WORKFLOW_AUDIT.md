# AetherMesh Public Workflow Audit

## CTA
**Give us one repetitive workflow. We'll show you where AI agents could fit, what should remain human-controlled, and how to test it.**

## Intake
1. Company
2. Website
3. Workflow name
4. Who performs it?
5. Frequency
6. Systems involved
7. Current failure points
8. Approximate time/cost
9. Actions requiring approval
10. Pilot success definition

## Audit output
### Workflow map
Trigger -> inputs -> reasoning -> actions -> approvals -> output -> feedback

### Agent opportunities
Identify specialist roles only where they add value: research, analyst, writer, reviewer, engineer, sales, finance, support, security.

### Human control
Classify actions as observe, prepare, execute, commit. Consequential commits require explicit approval unless documented customer policy permits automation.

### Evaluation
Define accuracy, completion rate, cycle time, escalation rate, cost per workflow, and human intervention rate.

### Pilot
Specify scope, data boundary, integrations, approval gate, success threshold, rollback path, and business owner.

## Example
Workflow: Customer onboarding.

Potential system:
Research Agent -> Intake Agent -> Implementation Agent -> QA Agent -> Human Approval -> Customer Update.

Human control remains for exceptions, contractual decisions, and irreversible account changes.
