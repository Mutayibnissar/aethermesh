# AetherMesh Revenue Model

## Initial pricing hypothesis

| Product | Price |
|---|---:|
| Workflow Scan | Free |
| Workflow Map | $1,500 |
| Workflow Pilot | $5,000–$12,000 |
| Production Workflow | $12,000–$35,000 |
| Managed Agent Operations | $3,000–$15,000/month |

## Example paths

### Conservative
2 Workflow Maps × $1,500 = $3,000
1 Pilot × $7,500 = $7,500
1 Managed customer × $3,000 = $3,000 MRR

### Productization path
After repeated delivery, extract the most common workflow into a hosted product with:
- workspace
- workflow templates
- agent selection
- execution history
- evaluation dashboard
- approval queue
- usage controls
- billing

## Unit economics to track

Revenue:
- average contract value
- monthly recurring revenue
- expansion revenue

Delivery:
- model/API cost per workflow
- compute cost
- human hours
- integration cost
- support hours

Quality:
- successful workflow runs
- intervention rate
- failure rate
- customer acceptance rate

The business should increase automation only when measured quality and customer acceptance justify it.

## Billing implementation

AetherMesh can use subscription or hybrid billing once the hosted product exists. Stripe currently documents subscriptions, usage-based billing, invoices, payment links and 100+ payment methods for its India platform. See the official Stripe pricing documentation before implementation.
