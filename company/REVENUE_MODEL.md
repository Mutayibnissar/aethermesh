# AetherMesh Revenue Model

## Revenue streams

### 1. Diagnostic revenue
AI Opportunity Maps create paid entry points.

### 2. Implementation revenue
Workflow builds and transformation programs generate project revenue.

### 3. Recurring managed operations
Agent Pods and Managed Agent Operations create recurring revenue.

### 4. Reusable workflow products
Validated workflows can become standardized packages for a vertical.

### 5. Enterprise platform
Longer term, AetherMesh can expose orchestration, evaluation, governance, and workflow analytics as a software platform.

## Unit economics to track

- acquisition cost per qualified opportunity
- opportunity-map conversion rate
- pilot conversion rate
- implementation gross margin
- monthly recurring revenue
- net revenue retention
- model/tool cost as % of revenue
- human intervention minutes per successful workflow
- incident rate
- workflow success rate
- expansion revenue per account

## Strategic progression

**Services → Productized Services → Managed Agent Pods → Workflow Products → Platform**

The services layer is the learning engine. Every repeated engagement should reduce custom work and increase reusable IP.

## Example account expansion

Opportunity Map → $5k diagnostic → $15k workflow build → $10k/month managed pod → second/third workflow → enterprise transformation.

These are illustrative commercial scenarios, not forecasts or guaranteed economics.
