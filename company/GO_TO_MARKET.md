# AetherMesh Go-To-Market

## Beachhead

Sell to startup and digital-first teams with:
- a recurring workflow
- an identifiable owner
- enough volume to justify automation
- accessible systems/data
- willingness to run a controlled pilot

## Acquisition

### Channel 1 — Public workflow teardowns
Publish useful analyses of real business workflows without claiming confidential knowledge.

CTA:
**Submit one workflow for a free AetherMesh Workflow Scan.**

### Channel 2 — Founder/operator communities
Contribute workflow analysis first. Invite qualified founders to a short workflow clinic.

### Channel 3 — Product-led open source
The public repository remains the technical trust layer. Commercial value comes from governance, hosted execution, integrations, evaluation, deployment and managed operations.

### Channel 4 — Partnerships
Partner with:
- startup accelerators
- fractional CTO/COO firms
- RevOps consultants
- product agencies
- implementation partners

## Sales motion

1. Free Workflow Scan
2. 30-minute workflow clinic
3. $1,500 Workflow Map
4. $5k–$12k Pilot
5. $12k–$35k Production
6. $3k–$15k/month Managed Agent Operations

## Qualification questions

1. What workflow repeats every week?
2. Who owns it?
3. What triggers it?
4. What inputs are required?
5. Which steps require judgment?
6. What must remain human-approved?
7. How many times does it run each month?
8. What does failure cost?
9. Which systems contain the required data?
10. What metric would prove the pilot useful?

## Do not sell
Do not sell generic "AI transformation" before identifying a workflow. The unit of sale is a measurable workflow.

## First outbound asset
One personalized hypothesis per qualified company:
- current workflow signal
- likely bottleneck
- proposed agent workflow
- approval boundary
- evaluation metric
- pilot scope
