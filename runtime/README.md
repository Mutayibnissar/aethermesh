# AetherMesh Runtime

A provider-neutral execution layer for the Agency Agents corpus.

Capabilities: recursive Markdown discovery, deterministic routing, safety policy gates, dependency-aware workflow planning, evaluation, and Node 20+ support with zero runtime dependencies.

CLI: npm test; npm run cli -- list; npm run cli -- route "design a secure API"; npm run cli -- plan "launch a product"; npm run cli -- policy "delete production database".

Provider adapters can later target OpenAI, Anthropic, Gemini, Ollama, local models, or other execution backends without changing agent definitions.
